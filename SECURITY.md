# Security and bug bounty

## Reporting a security problem

Please **don't** open a public issue or post about it. Report it privately:

- **In the game:** Profile → Bug bounty → Report a bug (choose "Critical" or "High"). This is the fastest way and you'll
  see our reply and any reward there.
- **On X:** DM [@slabhuntfun](https://x.com/slabhuntfun) and we'll set up a private channel.

Security problems include anything that lets someone change game results the server should decide, take coins, items,
NFTs or tokens that aren't theirs, see another player's private data, or affect the $SLAB token, pool or treasury.

## Rewards

Bug bounty rewards are paid in **$SLAB**, decided case by case by the team, and sent from the treasury multisig after the
fix ships. Bigger impact means a bigger reward. The first clear report of an issue is the one rewarded.

**Not allowed** (and voids a reward): testing against other players' accounts or funds, denial of service or flooding,
social engineering or phishing, publishing details before a fix, or keeping anything obtained through the bug.

Rewards are at the team's discretion, may be subject to local laws and taxes where you live, and can't be paid where
that's prohibited.

## Non-security bugs

Regular bugs (something looks wrong or doesn't work) can go through the same in-game form, or as a GitHub issue using the
bug report template.
